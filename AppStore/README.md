# App Store assets — 0.2.0

On 9 October 2026, the owner confirmed that Apple had published the app. The GitHub release [v0.2.0](https://github.com/jorgepb96/nodus-presenter-mobile/releases/tag/v0.2.0) preserves the current source state, version **0.2.0 (23)**, and the accompanying App Store assets. The dated submission and draft notes below are historical records.

Store name: **Nodus Presenter**. Nodus Research is the companion desktop application. Build 9 also pairs with its Windows/Linux Presenter integration on the same local network. Build 11 improves iOS-side Mac discovery/TLS startup and resource recovery; the desktop Mac helper and TLS-PSK protocol remain unchanged.

`Metadata` contains descriptions, subtitles, promotional text, keywords and release notes for en-US, es-ES, fr-FR, de-DE, it, pt-PT, ja, zh-Hans and zh-Hant. All descriptions now cover Mac, Windows and Linux, their connection requirements, and platform-specific volume behavior. Fields were checked against App Store Connect character limits. The initial App Store submission has no “What's New” field; these files are retained for subsequent releases. `reviewNotes.txt` contains the English instructions prepared for Apple's reviewers.

The fourteen store screenshots are **in English** and show the actual local demo of build 5. Build 8 updates the small header logo and welcome mark; separate native brand validation captures are available in `Screenshots/Brand`. No composited device frames or generated interface mockups are used.

Current captures can be generated with `StoreScreenshotTests/testEnglishStoreScreenshots`. From build 23, private reading and Spotlight replace the obsolete demo video and volume captures. The test selects English by launch arguments, resets app preferences, rotates iPad before launch and exports the complete display as an opaque PNG with normalized orientation. The screenshot test is explicitly selected; it is not needed for routine unit-test runs.

Build 23 removes all video and volume controls from the offline demo, including Settings. Real playback occurs on the paired computer. Mac volume controls system output; Windows/Linux volume controls the presentation video. In real sessions these controls are hidden for slides without a video and while reading privately.

The owner's physical tests of build 11 still hang during Mac/iPhone pairing on university Wi-Fi and with Wi-Fi enabled but disconnected from infrastructure; the same devices connect promptly using the iPhone's personal hotspot. The direct-connection issue is unresolved and cannot be explained solely by campus restrictions. A local Mac browser observes the current service on the peer-to-peer interface, but this does not prove discovery/authentication from the iPhone. Opt-in DEBUG logs from a physical iPhone now show that USB carried the successful connection; after unplugging, the Wi-Fi attempt remained in preparation and timed out before TLS. Later discovery probes were inconclusive because the desktop Presenter session had closed. Both local-network permissions were confirmed enabled. Mobile Bonjour/lifecycle/permission corrections are prepared following Apple's documentation, but the owner is currently unavailable for another physical test. No replacement has been uploaded or declared ready for review. See `Docs/ConnectionInvestigation.md`.

Seven iPhone and seven iPad images are complete. The obsolete unuploaded duplicate iPhone reservation was removed through Apple's official API using the existing Apple key in GitHub Actions. Verification compared screenshot IDs before and after and confirmed that all valid images and their exact order, including the iPad set, were preserved. No new API key was created. The temporary maintenance branch was removed and no release workflow change was merged.
